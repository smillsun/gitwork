部署流程

  1. 1

    推送到仓库

    把改动提交并推送到 GitHub 仓库的 main 分支。

  2. 2

    开启 Pages

    在仓库 Settings → Pages 中，将 Source 设为 Deploy from a branch，分支选 main、目录选 / (root)。

  3. 3

    访问站点

    稍等 1–2 分钟，站点即在 https://<用户名>.github.io/<仓库名>/ 上线。

快速开始

克隆、修改、推送，三步上线。

git clone https://github.com/<用户名>/gitwork.git
cd gitwork
# 编辑 index.html / assets/css/style.css
git add .
git commit -m "Update site"
git push origin main
